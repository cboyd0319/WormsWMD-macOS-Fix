This record covers the October 2–3, 2026 investigation, fixes, reviews, runtime

## Reported failures and corrections

[Issue #30](https://github.com/cboyd0319/WormsWMD-macOS-Fix/issues/30)
reported missing QtDBus, QtSvg, and AGL on an M3 Mac running macOS 26.6.2.
[Issue #31](https://github.com/cboyd0319/WormsWMD-macOS-Fix/issues/31)
reported a macOS 27 SDK text-stub/linker failure on an M1 Mac running 26.6.2.
The latter installer rolled back successfully. The precise original Apple
toolchain environment was not reproduced on the validation host.

[PR #33](https://github.com/cboyd0319/WormsWMD-macOS-Fix/pull/33), merged as
`49cc604d0b0f8b6ea33a86b4f2071f2843986ad6`, made these corrections:

- Resolve Apple's compiler and SDK together, avoid a poisoned `PATH` or
  inherited deployment target, try installed sibling SDKs, and remove unused
  OpenGL linkage. Preserve both x86_64 and arm64 AGL slices.
- Compile before backup or game mutation. Refuse stale or incomplete build
  output and provide Command Line Tools recovery guidance if all SDKs fail.
- Sign the modified bundle before strict verification, keeping signing and
  verification failures inside transactional rollback.
- Include sanitized compiler/SDK evidence in support bundles.
- Add checksum-pinned Intel PCRE2 source builds and preserve approved source
  rows during dependency refresh. Reject new source versions without review.
