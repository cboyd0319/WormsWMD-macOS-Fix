# Assets

This folder contains original visuals for the community fix. Assets here should
make the project easier to recognize without copying official game art.

Current assets:

- `geocities-chaos-banner.svg` - intentionally loud README banner.
- `webring-control-room.svg` - intentionally chaotic fake web-ring control
  panel for the README.
- `under-construction-strip.svg` - intentionally awful retro construction bar.
- `visitor-counter.svg` - fake retro visitor counter for README flavor.

Do not add official Team17/Worms artwork or third-party sample assets unless the
license and attribution are committed with the asset.
