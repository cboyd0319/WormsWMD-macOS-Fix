# Steam Forum Post Template

You can copy and paste this into a Steam discussion when someone is stuck.

```text
If Worms W.M.D opens to a black screen on newer macOS, try this community fix:

https://github.com/cboyd0319/WormsWMD-macOS-Fix/releases/latest

Easiest steps:
1. Download the release zip.
2. Unzip it.
3. Double-click "Worms W.M.D Fix.command".
4. Choose option 1.

If macOS blocks it, right-click the file and choose Open.

If it fails, run the same file again and choose option 5. That creates a support
bundle on your Desktop that can be attached to a GitHub issue.
```
