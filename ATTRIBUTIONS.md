# Attributions And Asset Policy

This is an unofficial community compatibility project for Worms W.M.D on macOS.
It is not affiliated with, endorsed by, or sponsored by Team17.

`Worms W.M.D` and related names, characters, logos, screenshots, and game art
belong to their respective owners. The repository uses the game name only to
identify the compatible title.

Official reference pages:

- Team17 legal terms: https://www.team17.com/legal/
- Worms W.M.D official page: https://www.team17.com/games/worms-w-m-d/

## Bundled visuals

- No decorative project artwork is currently bundled.
- No official Team17 or Worms artwork is bundled.
- No WebPets sample assets are bundled.

## PCRE2 runtime

The Intel runtime includes [PCRE2 10.49](https://github.com/PCRE2Project/pcre2/releases/tag/pcre2-10.49),
built from the checksum-pinned upstream source. Its
[PCRE2 notice](packaging/PCRE2-LICENSE.txt) and
[SLJIT notice](packaging/PCRE2-SLJIT-LICENSE.txt) are copied verbatim from that
release and included in the Qt archive's `METADATA.txt`.

## Adding assets later

Only add third-party art, screenshots, GIFs, icons, or sprites when the exact
license permits redistribution in this repository. Commit the license text or a
source link and attribution in this file at the same time as the asset.

Official Team17 or Worms assets should not be committed unless explicit written
permission or a redistributable license is documented here.
